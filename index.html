Market Size Ledger

その市場規模、
どの数え方？

同じ年の同じ市場でも、出荷か小売か、国内生産だけか輸入を含むか、年度か暦年かで、数字は倍以上変わります。この台帳は、出典ごとの数字を定義と一緒に並べて、引用するときの取り違えを防ぎます。

Rules

台帳の書き方

数字を足すときの6つのルール。くわしくは使い方ガイドと用語集へ。

  1. 1つの数字 = 1行1つの記事に5つの数字があれば5行になる。
  2. 誰が・何ベースで・どの期間か数字は必ず定義とセットで書く。分からない項目は空欄にせず unknown / null と明記する。
  3. 確認したことだけ書く原典の文面で確認した数字は verified、記事やまとめサイト経由でしか見ていない数字は unverified。推測で埋めない。
  4. 原典と経由先を分ける数字を作ったのは誰か（source）と、どこで読んだか（via）を別の項目にする。
  5. 計算値は保存しない前年比・構成比・倍率は画面で計算する。保存するのは原典に書かれた絶対値だけ。
  6. 古い数字も消さない予測が実績に置き換わっても両方の行を残す。改訂の履歴になる。

データは data/ にあります。行を足したら node tools/validate.mjs で検証してください。
