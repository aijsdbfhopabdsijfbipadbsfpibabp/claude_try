市場規模の出典台帳

出典ごとにバラバラな「市場規模」の数字を、定義と一緒に並べて見るための台帳です。同じ年の同じ市場でも、数え方（出荷か小売か、国内生産だけか輸入を含むか、年度か暦年か）で数字は倍以上変わります。その違いを見える形にして、引用するときに取り違えないようにします。

台帳の書き方

  1. 1つの数字 = 1行。1つの記事に5つの数字があれば5行になる。
  2. 数字は必ず「誰が・何ベースで・どの期間か」とセットで書く。定義が分からない項目は空欄にせず unknown / null と明記する。
  3. 確認したことだけ書く。原典の文面で確認した数字は verified、ニュース記事やまとめサイト経由でしか見ていない数字は unverified。推測で埋めない。
  4. 原典と経由先を分けて記録する。数字を作ったのは誰か（source）と、どこで読んだか（via）を別の項目にする。
  5. 計算で出せる値は保存しない。前年比・構成比・倍率は画面で計算する。保存するのは原典に書かれた絶対値だけ。
  6. 古い数字も消さない。予測が実績に置き換わっても両方の行を残す（改訂の履歴になる）。

データは data/ にあります。行を足したら node tools/validate.mjs で検証してください。用語は用語集にまとめています。

数字は各原典の利用条件に従って扱ってください。調査会社の数字は、転載に許諾が必要な場合があります（再利用の可否）。
