使い方ガイド

市場や経済の数字に慣れていない人向けに、この台帳の読み方と使い方を順番に説明します。5分ほどで読めます。

1. なぜこの台帳があるの？ 2. まず覚える5つの言葉 3. 画面の見かた（順番に） 4. 数字を引用するときの手順 5. 数字を足す（更新する） 6. よくある質問

1. なぜこの台帳があるの？

「化粧品の市場規模は？」と調べると、2.6兆円と書く記事もあれば、1.4兆円や3.2兆円と書く記事もあります。どれかが間違っているわけではありません。数え方が違うのです。

たとえるなら「クラスの身長」を、靴を履いて測るか、裸足で測るか、の違いです。測り方が違えば数字も違います。この台帳は、数字を「誰が・どう数えたか」と一緒に並べて、取り違えを防ぐための道具です。

2. まず覚える5つの言葉

出荷額 と 小売額
メーカーがお店に売った金額（出荷額）と、お客さんがお店で払った金額（小売額）。お店の儲けが乗るぶん、小売額のほうが大きくなります。
年度 と 暦年
暦年は1月〜12月。年度は4月〜翌年3月。「2024年度」と「2024年」は、9か月しか重なっていません。
実績・速報・予測
実績は確定した数字、速報はあとで変わるかもしれない数字、予測は未来の見込みです。予測を実績のように使わないことが大切です。
原典 と 経由先
原典は数字を作った人（調査会社や国など）。経由先は、自分がその数字を読んだ場所（ニュース記事やまとめサイト）。又聞きの数字は写し間違いがあり得ます。
確認済み・未確認・要確認
原典で数字を見て確かめたものが「確認済み」。記事でしか見ていないものが「未確認」。どこか怪しいものが「要確認」です。

もっと詳しい説明は用語集にあります。

3. 画面の見かた（順番に）

  1. 市場一覧を開く
    トップページ（市場一覧）に市場ごとのカードがあります。大きな数字は「数え方によって、この範囲に数字が散らばっている」という幅です。カードを押すと、その市場のページに移ります。
  2. 上の「セグメント」を選ぶ
    「全体」「スキンケア」など、見たい範囲を選びます。最初は「全体」のままで大丈夫です。
  3. 「定義の幅」を見る（いちばん大事）
    その年の数字が、小さい順に横棒で並びます。棒の色が数え方を表します。棒の左に、誰の数字か・年度か暦年か・何を含むか（✓含む／✗含まない／?不明）が書いてあります。
    → ここで「同じ年でもこんなに違うのか」をつかみます。右上の ◀ ▶ で年を変えられます。
  4. 「時系列」で流れを見る
    同じ数え方の数字だけを線で結んでいます。実線は実績、破線は予測です。点にマウスを乗せると詳しい情報が出ます。違う色の点どうしは比べられない（数え方が違う）と考えてください。
  5. 「定義マトリクス」で中身を比べる
    表で「どの数字が何を含んでいるか」を✓✗?で一覧できます。?が多い数字は、まだよく分かっていない数字です。
  6. 「一覧表」で元の数字を探す
    すべての数字が表になっています。上の選択欄で絞り込めます。出典名を押すと、元の記事や資料のページが開きます。
  7. 「改訂と不一致」「要確認リスト」で注意点を見る
    予測があとで実績に変わったもの（改訂）や、同じ資料のはずなのに記事によって数字が違うもの（不一致）が並びます。ここに出ている数字は、使う前に気をつけましょう。

4. 数字を引用するときの手順

レポートや発表で市場規模を使うときは、次のチェックをしてください。

  1. 使いたい数字を「定義の幅」か「一覧表」で見つける。
  2. 確認状態を見る。「△ 未確認」「! 要確認」が付いていたら、出典名を押して原典で確かめる（できなければ「〜とされる」と書く）。
  3. 予測でないか確かめる（「予測」のタグ）。
  4. 数字と一緒に3点セットを書く。
    2兆6,430億円（矢野経済研究所、2025年度、メーカー出荷金額ベース）
  5. 別の出典の数字と比べるときは、数え方と年度/暦年がそろっているか確かめる。そろっていなければ「数え方が違うので単純比較できない」と添える。

「計算」の印が付いた数字（前年比など）は、この画面が計算した値で、原典に書かれた数字ではありません。また、調査会社の数字は転載に許可が必要なことがあります。

5. 数字を足す（更新する）

新しい記事で市場規模の数字を見つけたら、台帳に足していきます。いちばん簡単なのは Claude に頼む方法です。

  1. 記事のURLをコピーする。
  2. Claude に この記事の数字を台帳に追加して: https://… と送る。
  3. Claude が数字を拾って追加し、チェックまでしてくれます。返ってきた報告で「不一致」などの注意が出ていないか見る。
  4. 反映されたら、サイトを開き直して数字が増えたことを確かめる。

新しい市場（たとえば「ビール」）を始めたいときは、「ビール（日本）」の市場を追加して と頼めば、追加案を出してくれます。

自分で直接書きたい人向け

数字は data/observations/市場ID.jsonl に、1つの数字を1行で書きます。既存の行をコピーして、値・年・出典を書き換えるのが簡単です。出典が新しければ data/sources.json にも足します。保存して GitHub に送ると、書き間違いがないか自動でチェックされます。

ルール: わからない項目は推測で埋めず unknown や null にする／記事でしか見ていない数字は unverified にする／古い数字も消さない。

6. よくある質問

結局、どの数字が「正しい」の？
どれも、その数え方では正しい数字です。目的に合う数え方を選びます。メーカーの売上規模を知りたいなら出荷額、消費者がいくら使っているか知りたいなら小売額、が目安です。
薄く表示されている数字は？
同じ発行元の新しい発表で置き換わった古い数字です。履歴として残しています。普段は濃いほうを使ってください。
「≠」や「不一致あり」は？
同じ資料が元のはずなのに、記事によって数字が違うものです。原典で確かめるまでは使わないほうが安全です。
ファイルを開いても何も表示されない
ファイルを直接ダブルクリックすると動きません。公開されたURL（GitHub Pages など）で開くか、npx serve . で開いてください。

数字は各原典の利用条件に従って扱ってください。調査会社の数字は、転載に許諾が必要な場合があります（再利用の可否）。
