Glossary

用語集

台帳の項目の意味を短くまとめています。表の「値」が、台帳のファイルに書く文字列です。

原典と経由先 年度と暦年 出荷と小売（数え方） 範囲（含む・含まない） 実績・速報・推計・予測 確認状態 単位 系列 改訂と不一致 計算値 出典の種類 入手性と再利用の可否

原典と経由先（source / via）

原典は、その数字を作った人・組織の資料です（調査会社のプレスリリース、政府統計など）。経由先は、自分がその数字を実際に読んだ場所です（ニュース記事、まとめサイトなど）。

台帳では source に原典、via に経由先の出典IDを書きます。原典で直接読んだときは via を null にします。原典が分からないときは source を "unknown" にします。経由先で読んだ数字は、書き写しの誤りや古い版の引用が混じることがあるので、原典で確かめるまで「未確認」として扱います。

年度と暦年（period_type）

暦年は1月〜12月、年度は4月〜翌3月です。「2024年度」は2024年4月〜2025年3月なので、「2024年」とは9か月しか重なりません。調査会社は年度、貿易統計や生産動態統計は暦年で集計することが多く、同じ「2024」でも期間がずれます。

時系列グラフでは各期間の中心に点を置きます。暦年の2024は2024年7月1日、年度の2024は2024年10月1日の位置です。年度か暦年か分からない数字は暦年の位置に置き、点に「?」を付けます。

出荷と小売（basis = 数え方）

市場規模の数字は、どの段階のお金を数えるかで大きく変わります。メーカー出荷額はメーカーが卸・小売に売った金額、小売・購入額は消費者が支払った金額に近い数え方で、流通の取り分のぶん小売のほうが大きくなります。国内生産の出荷額は国内工場で作った分だけなので、輸入品を含みません。

受託製造（OEM）の売上や輸出入額は、市場規模そのものではなく関連指標です。セグメント定義で related: true を付けて区別します。

範囲（scope：含む・含まない）

数え方が同じでも、何を含めるかで数字は変わります（化粧品なら輸入品や医薬部外品を含むか）。判断材料になる項目は市場ごとに scope_flags として決め、各行の scope に true（含む）/ false（含まない）/ null（不明）を書きます。書いていない項目は「不明」として扱います。

画面では ✓ = 含む、✗ = 含まない、? = 不明 で表します。

実績・速報・推計・予測（status）

速報はあとで確定値に置き換わる値、推計は実績の期間についての見込み、予測は将来の期間の値です。時系列グラフでは、実績は実線、予測は破線、推計は点線、速報と推計は白抜きの点で描きます。

確認状態（check）

原典の文面で確かめた数字だけを「確認済み」にします。経由先でしか見ていない数字は「未確認」、年・定義・原典のどれかに疑問がある数字は「要確認」です。原典が分からない数字（source: "unknown"）は確認済みにできません。

単位（unit）

台帳には原典に書かれたままの値と単位を保存し、画面で億円にそろえます。大きな数字は「2兆6,430億円」の形で書きます。ドル建ての数字は為替の前提が入るので円に換算せず、別の軸（別のグラフ）で表示します。

系列

出典（source）・数え方（basis）・期間の種類（period_type）・セグメント・範囲（scope）がすべて同じ数字の並びを、1つの系列と呼びます。時系列グラフで線で結ぶのは同じ系列の点だけです。定義の違う点どうしを結ぶと、数え方の違いが「増減」に見えてしまうからです。

同じ系列・同じ期間に複数の数字があるときは1つを標準表示にし、ほかは薄く表示します。

改訂と不一致

改訂: 同じ発行元・同じ期間・同じ定義で、発行日の違う数字です。たとえば前年の発表では予測だった値が、翌年の発表で実績になったもの。古い数字も消さずに残し、画面では新しい発表を標準表示、古い発表を薄く表示します。

不一致: 同じ原典を名乗るのに、経由先によって値が違う数字です。経由先が集計範囲を変えている、書き写しを誤っている、などの可能性があるので、原典の文面で確かめるまではどちらも引用しないほうが安全です。

計算値

前年比・倍率・構成比は台帳に保存せず、画面で計算します。計算した値は 104.1%計算 のように、斜体と「計算」の印で原典の値と区別します。原典に書かれた比率（「前年度比104.1%」など）は、各行の注記（note）に原文のまま残します。

入手性（access）と再利用の可否（license）

再利用の可否は、台帳を公開するときの表示ルールに使います。公開版では、open の出典の数字だけを表示し、restricted / unknown の出典は出典名・期間・定義・リンクだけを出して数字を伏せる予定です。
